CRM_PK_OP2MEM_LE

typedef void (*FUNC_CRM_PK_OP2MEM_LE)(const crm_op *op, char *mem, int sz);
#define CRM_PK_OP2MEM_LE ((FUNC_CRM_PK_OP2MEM_LE)(*(uint32_t *)(API_TABLE_BASE_ADDRESS + ATO_CRM_PK_OP2MEM_LE)))

Description

Write the operand into memory filling 'sz' bytes, 0-pading if needed in little endian format

Parameters

ParamDescription
opOperand written to memory. Data should have a size smaller or equal to 'sz'
memMemory address to write the operand to
szSize in bytes of the operand

Returns

None

DEVICE_SLEEP_ConfigWssLowPowerMode Function

C

void DEVICE_SLEEP_ConfigWssLowPowerMode(void);

Description

The API is used to bring the wireless subsystem in low power mode.\n It should be called when the application requests the device into deep sleep or xtreme deep sleep mode.

Parameters

None

Returns

None

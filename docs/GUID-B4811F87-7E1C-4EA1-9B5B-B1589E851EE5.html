1.3.3.1.18 PDS_Store Function

C

bool PDS_Store(PDS_MemId_t memoryId);

Description

This routine stores data in non-volatile memory in background, not blocking other processes. Make sure the item/file size is less than MAX_FILE_SIZE

Parameters

ParamDescription
memoryIdan identifier of PDS file or directory to be stored from non-volatile memory

Returns

True, if storing process has begun, false - otherwise.
